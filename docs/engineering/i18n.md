# Skiff 国际化

简体中文 `zh-CN` 是文案基准，英文 `en` 和繁体中文 `zh-Hant` 与基准同步维护。词库位于 [presentation/i18n/catalogs](../../internal/contexts/transfer/presentation/i18n/catalogs)，由 MyGo 的 MessageFormat 解析。每个语言使用一个文件，使用同一组按功能命名的语义键，例如 `download.new`。词库文件就是可用语言的登记。设置中默认跟随系统，未匹配时回退到简体中文。手动选择即时生效，MyGo 保存语言偏好并在下次启动恢复。

macOS 的语言声明位于 `mygo.json`。简体中文词库 `zh-CN` 对应包语言 `zh-Hans`，繁体中文使用 `zh-Hant`。新增语言时同步维护应用包语言声明，并在桌面装配中接入 MyGo 已提供的同语言控件词库。

界面标题、动作、可访问标签、校验提示和错误映射归表现层。参数使用同名占位符，由完整句子决定顺序。文件名、路径、链接、协议标识及外部系统内容按原始值传递。业务层故障用稳定标识表达，由表现层选择对应文案。

`make check-i18n` 检查词库键、非空文案、格式和命名参数。静态门禁还会扫描表现层和桌面装配的 Go AST，检查词库外的中文及常见 MyGo 文案入口中的硬编码文本，也校验静态翻译调用的键和命名参数。问题会报告文件位置。该契约也随 `make check` 与 CI 的 Go 契约测试运行。
