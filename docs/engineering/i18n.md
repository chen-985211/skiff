# Skiff 国际化

简体中文 `zh-CN` 是文案基准，英文 `en` 与中文同步维护。词库位于 [presentation/i18n/catalogs](../../internal/contexts/transfer/presentation/i18n/catalogs)，由 MyGo 的 MessageFormat 解析。每个语言使用一个文件，使用同一组按功能命名的语义键，例如 `download.new`。

界面标题、动作、可访问标签、校验提示和错误映射归表现层。参数使用同名占位符，由完整句子决定顺序。文件名、路径、链接、协议标识及外部系统内容按原始值传递。业务层故障用稳定标识表达，由表现层选择对应文案。

`make check-i18n` 检查词库键、非空文案、格式和命名参数。该契约也随 `make check` 与 CI 的 Go 契约测试运行。
