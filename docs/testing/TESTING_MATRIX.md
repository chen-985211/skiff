# 测试选择矩阵

| 修改 | 最低验证 |
| --- | --- |
| 链接、状态、进度与动作资格 | unit 参数矩阵 |
| 添加/暂停/继续/重试/移除/恢复用例 | unit：Engine/Repository 端口替身 |
| JSON-RPC 参数、鉴权与错误 | integration：本地 HTTP RPC 服务 |
| 文件仓储与版本 | integration：真实临时文件、损坏与往返 |
| aria2 生命周期与恢复 | integration：真实 aria2 + 本地下载服务 |
| UI 输入、筛选、布局、空/错误状态 | MyGo 无窗口组件测试，使用静态背景与实色控件检查点击、焦点、边界和状态 |
| 动效、材质、轮廓 | 动效测试保留实际过渡并推进测试时钟；颜色、透明度和轮廓使用真实软件渲染采样 |
| 同一面板内切换标签或编辑器 | 渲染检查首帧、中间帧、反向和终态，验证公共控件对齐、短标签完整、键盘焦点和减少动态效果。本机回看一次往返切换录屏 |
| 国际化、结构化日志与错误码 | contract：词库、文案及错误边界；unit：语言切换、错误反馈和日志输出 |
| 分层与依赖 | contract：解析实际 Go import |
| 打包与启动 | build + 本机产物启动检查 |
| 文档与格式 | 相关链接、命令与格式检查 |
