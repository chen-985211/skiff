# Skiff 桌面版 BT、磁力与做种

本阶段从普通文件下载分支独立开发。新建面板左上角切换「链接 / BT」，每项目标单独验证和提交。

| 项 | 用户可完成的任务 | 验收方式 |
| --- | --- | --- |
| 1 种子选文件 | 打开本地 v1 种子，或先获取磁力元数据。浏览文件树并选择文件，可配置等待选文件超时后下载全部。 | 多文件种子与磁力、部分选择、取消、任务恢复 |
| 2 Tracker 与节点 | 管理订阅、自动刷新和查看健康状态，配置 DHT、局域网发现、监听端口及节点上限，查看节点、Tracker 和分片进度。 | 本地订阅与引擎观测 |
| 3 做种与已有文件 | 按分享率或时长结束做种。重新定位、移动并校验已有文件，保留历史，可选择恢复做种。 | 本地样本、内容校验、暂停与恢复 |
| 4 创建种子 | 从文件或目录生成 BitTorrent v1 种子，选择保存位置，可使用原文件做种。 | 独立解析种子、核对分片、原文件做种 |

本阶段范围为 Skiff 桌面端。

第 1 项已通过本机 aria2 验证。独立做种进程与回环 Tracker 提供磁力元数据；选文件前目标目录为空。两文件种子只选第二项时，落盘内容与选择一致。

第 2 项已通过本地订阅与 aria2 测试。订阅失效时保留上一次的列表，任务可单独调整节点上限，详情读取实际节点与分片。

第 3 项已验证完整 BT 文件的分片校验、重新定位、跨目录移动与恢复做种。复制目标独占创建，校验和任务位置保存成功后才清理原目录的种子文件。做种时间在本机设置为一分钟后，aria2 自动停止。
