# Skiff 普通文件下载目标

日常流程是粘贴链接、确认保存位置、开始下载。任务特有参数按需展开，全局带宽与队列设置集中管理。

十二项普通文件下载目标均已实现。下表保留每项的范围，桌面验收入口列在文末。

| 编号 | 目标 | 完成标准 |
| --- | --- | --- |
| 1 | HTTP / HTTPS | 跟随重定向，采用服务端文件名。暂停或重启后可从断点继续。已有版本标识随下载请求发送；缺少标识时直接使用原任务的断点。服务器拒绝续传时保留原文件，由用户决定是否另起文件。 |
| 2 | FTP | 接受 FTP 文件直链，支持匿名、账号密码、被动模式和服务端允许的续传。遇到认证时再提示。远程目录浏览留待后续。 |
| 3 | 批量添加 | 每行一个链接，逐行校验并去重。有效链接入队，新增、重复和无效数量可见，错误行保留供修改。 |
| 4 | 剪贴板与 cURL | 同一输入框接受单条、多条或浏览器复制的 cURL。主动粘贴触发解析，仅提取下载参数。 |
| 5 | 认证与请求头 | 可导入和编辑 Cookie、Authorization、Referer、User-Agent 及自定义头。敏感值遮盖，跨域重定向隔离原站凭据。 |
| 6 | 保存与命名 | 支持默认、单次和最近目录，批量共用目标目录，单文件可改名。重名默认保留两份。 |
| 7 | 多连接分段 | 默认自动，依据文件大小和来源的 Range 能力使用合适的并行度。小文件或不支持分段的来源可单连接完成；可覆盖单文件连接上限，详情显示实际连接数。 |
| 8 | 队列与并发 | 全局默认 10 个并发任务，用户可更改并在重启后保留。满额时排队，空位自动补上，可指定下一个优先下载的等待任务。 |
| 9 | 性能与磁盘 | 默认自动，可自定义缓存、最小分段、预分配并恢复默认。额外档位以实测收益为依据。 |
| 10 | 多镜像 | 显式为同一任务添加备用地址，失败后自动切换。验证内容一致才复用进度。多源并行拼接属于第二阶段。 |
| 11 | 下载限速 | 默认不限速，支持快速切换全局上限和更低的单任务上限。定时规则留待后续。 |
| 12 | 代理与 DNS | 默认跟随系统，支持直连、手动代理、认证、绕过列表和单任务代理覆盖。DNS 提供自动与系统解析。 |


## 桌面验收入口

| 项目 | 可在桌面端验证的行为 |
| --- | --- |
| 1 | 暂停再继续，观察进度从原处增长。恢复时直接请求缺少的分片。服务端拒绝续传且确认版本变化时，任务卡说明原因；选择从头下载后仍能找到原部分文件。移除任务后再粘贴同一链接，已有检查点和文件都保留。 |
| 2 | FTP 直链支持匿名和账号密码、被动传输及断点恢复；登录被拒时在任务卡输入凭据并继续。 |
| 3 | 一次粘贴两条相同的有效链接和一条无效链接。只新增一项，表单保留无效行并显示三个计数。 |
| 4 | 主动粘贴浏览器复制的 cURL，输入框显示文件地址，请求参数可在高级选项中编辑。导入只读取文本，不执行命令。 |
| 5 | 新建下载 → 高级选项 → 请求选项，可粘贴请求头或逐项编辑。Cookie、Authorization 和自定义值遮盖，原站凭据只随同源请求发送。 |
| 6 | 高级选项可为单文件改名，最近五个保存目录可直接选择。批量共用一次选择，默认目录独立保留。同名文件自动保留两份。 |
| 7 | 在新建任务的「高级选项」留空或输入 1～16。在任务详情查看实际连接数与本次上限。自动模式上限为 4，无法验证分段时使用单连接。 |
| 8 | 在「设置」调整同时下载数（默认 10，可选常用值或输入 1～200）。队列满额时把一个等待任务设为优先，观察它在下一个空位启动；重启后设置仍在。 |
| 9 | 设置 → 性能与磁盘。缓存下次启动生效，分段大小与预分配用于新任务。恢复默认并保存即可回到自动模式。 |
| 10 | 新建单任务时可在「请求选项」按行添加备用地址。来源失败后依次切换。匹配 SHA-256 表示摘要或同一最终资源的强 ETag 才复用断点，否则保留旧文件并另存。 |
| 11 | 在设置或任务详情快速切换限速档位，也可输入 KiB/s。全局与任务上限独立保存，运行中立即生效。 |
| 12 | 设置 → 代理与 DNS 可选择系统、直连或带认证的 HTTP 代理，设置绕过列表和 DNS。设置应用于新任务；单任务可在请求选项里覆盖代理。 |
