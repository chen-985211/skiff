# 轻舟 · Skiff

轻舟是一款桌面下载工具。把网页或消息里的 HTTP/HTTPS 文件链接粘贴进来，就能在一个窗口里查看下载进度、继续中断的任务，或找到已经下载的文件。

## 主要功能

- 批量添加链接，每行一个，同一批内自动去重，最多支持 100 个不同的链接。可以使用默认保存目录，也可以为这批文件另选位置。
- 按状态筛选任务，或按文件名、链接搜索。可以单独暂停或继续一个任务，也可以对筛选结果批量操作。
- 下载失败时可以查看原因并重试。遇到不支持续传的下载源，可以选择用新文件名从头下载，保留已下载的部分。
- 任务记录保存在本机，重启后原先进行中的任务会以暂停状态恢复。展开卡片能查看来源和保存路径，点击「位置」可在文件夹中定位文件。移除任务后，文件仍然保留。

## 快速开始

目前已在搭载 Apple 芯片的 Mac 上验证。要从源码启动，请先准备 Go 1.27.3 或更高版本。在仓库根目录运行以下命令，用 Homebrew 安装下载引擎 aria2 并启动轻舟。

```sh
brew install aria2
go mod download
make dev
```

看到主窗口后，点击「新建下载」或按 `⌘N`，粘贴文件链接，确认「保存到」的位置，再点击「开始下载」。默认保存目录是 `~/Downloads/Skiff/`。
