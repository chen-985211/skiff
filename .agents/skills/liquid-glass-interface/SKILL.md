# 液态玻璃界面

## 配色

| 角色 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| 环境底色 | 雾银 `#D6DAE4` | 蓝石墨 `#292E39` | 大面积背景 |
| 环境阴影 | 钢蓝 `#8A98B4` | 夜蓝 `#495469` | 背景折面、玻璃背光侧 |
| 材质表面 | 珠白 `#F8F9FA` | 岩灰 `#363C48` | 透色底层和内容阅读区 |
| 折射色 | 冰青 `#B9E5E7`、淡紫 `#C5B8D7` | 冷青 `#739CA9`、灰紫 `#9586A9` | 局部弧光、边缘色散 |
| 主文字 / 次文字 | `#1C2330` / `#475366` | `#F1F3F7` / `#C6CDD9` | 名称与当前值 |
| 主要操作 | 石墨 `#202532` | 珍珠灰 `#E6E7EB` | 高优先级按钮 |
| 进行 / 完成 / 暂停 / 错误 | `#365879` / `#46586F` / `#656477` / `#90465D` | `#A2CEFF` / `#CBBFFF` / `#D0C5D5` / `#FFB5BC` | 与状态图标、数值或错误原因配合 |

## UI 与 UX

- 配置项用列表。名称沿左侧基线排列，当前值和控件沿右侧对齐。可打开的行让整行响应点击。
- 可独立操作的对象用卡片。同一组使用相同的内边距、操作顺序和命中区域。状态变化时让符号、数值或局部色彩在原位更新。
- 窗口背景先铺开银蓝色的亮面与背光面，再沿弧面转折处露出短短一段珠光。让高光沿着曲面变亮、变细、隐入底色，两侧保留安静的留白。缓慢播放一整个循环，观察亮面、阴影和反光能否像同一片材质一样移动。
- 每张卡片用自身的坐标绘制流光背景。宽色带在卡面内部弯曲、交叠，边缘留少量珠光。为同一对象保留固定的相位偏移，展开、收起或换位时光纹跟随它。靠近文字的一侧收低振幅，进度和错误保留各自的语义色。
- 文字优先保留名称、当前值、操作和需要处理的错误。给图标操作提供可访问名称和键盘焦点。系统要求减少透明度或提高对比度时使用实色表面；减少动态效果时保留静态光泽。

## 动画曲线

弹簧参数按质量 1 计算。刚度决定响应速度，阻尼决定到达目标后是否回弹。

| 组件或属性 | 曲线 | 交互表现 |
| --- | --- | --- |
| 按钮按下与释放 | 刚度 900，阻尼 60 | 快速压下、平稳复位，命中区域固定 |
| 开关滑块 | 刚度 625，阻尼 40 | 轻微回弹；途中反向沿用当前速度 |
| 导航选中底板、分段选择 | 刚度 484，阻尼 44 | 底板经过中间位置，准确停在选项下方 |
| 面板收合 | 刚度 324，阻尼 36 | 面积越大，起停越从容；边界平稳收敛 |
| 卡片展开与收起 | 刚度 235，阻尼 31 | 从当前轮廓反向，保留速度，平稳停靠 |
| 颜色与文字替换 | 180 ms ease-in-out | 在原位交接，颜色采用感知均匀插值 |
| 有界数值与进度 | 200 ms ease-out | 从当前读数逼近新值，限制在合法范围内 |
| 材质流光 | 连续周期相位 | 用正弦或余弦驱动反光的位置和强度。循环首尾的位置与速度相接，停止时冻结当前相位 |

## 组件连续变形

小卡片展开为详情时，为两个形态保留同一个对象标识。取屏幕上当前可见的矩形作为起点，测量详情布局的目标矩形，让位置、宽高和圆角同时随弹簧演进。材质跟随当前轮廓重新绘制，同一束反光在展开中延续原有相位。

标题、图标等共有内容随主体移动。只在详情中出现的内容等空间足够时淡入，收合时提前淡出。输入焦点交给当前可操作的形态。用户在半途返回时，从这一帧的位置、尺寸和速度转向新的目标。

验收时连续执行展开、半途收合、再次展开，检查首帧、中间帧和终点。留意轮廓、文字、流光和点击位置是否始终对应同一个对象。减少动态效果时直接落到目标布局，保留状态和焦点反馈。
