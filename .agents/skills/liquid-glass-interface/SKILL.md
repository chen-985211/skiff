# 液态玻璃界面

先确定用户正在操作的对象、操作入口和结束后的落点。沿用目标产品的字体、间距、语义色和平台控件，再为需要表达层次或空间关系的表面选择玻璃材质和动效。

## 信息层级与布局

- **按任务分组。** 把用户需要一起判断或操作的内容放在一起，用间距区分组内与组间关系。让当前选择和主要操作容易辨认。如果控件已经说明用途，省去重复的标题。
- **用图标帮助辨认，用文字说清含义。** 常用且含义明确的动作可以单用图标。容易混淆的类别或动作保留简短标签，让用户初次使用、触屏操作时也能理解。
- **为同类内容建立共同的对齐线。** 先确定内容区的起止边缘，再让同类标签、值和操作沿同一列或同一基线排列。并列视图沿用这组对齐线，让用户切换后能在原位置找到同类信息。窄屏改成上下排列时，保留原有阅读顺序。
- **按需呈现复杂度。** 默认界面应能完成最常见的任务。有合理默认值的低频选项可按需展开，专属操作放在它能生效的对象旁。收起编辑区时保留输入，已改设置若会影响用户下一步的判断，在入口显示当前值或简短摘要。

## 配色与材质

下表是一套可直接采用的冷色参考。接入已有设计系统时，按第一列的角色映射现有色值，并在实际背景上检查文字、焦点和状态图标的辨识度。

| 角色 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| 环境底色 | 雾银 `#D6DAE4` | 蓝石墨 `#292E39` | 大面积背景 |
| 环境阴影 | 钢蓝 `#8A98B4` | 夜蓝 `#495469` | 背景折面、玻璃背光侧 |
| 材质表面 | 珠白 `#F8F9FA` | 岩灰 `#363C48` | 透色底层和内容阅读区 |
| 折射色 | 冰青 `#B9E5E7`、淡紫 `#C5B8D7` | 冷青 `#739CA9`、灰紫 `#9586A9` | 局部弧光、边缘色散 |
| 主文字 / 次文字 | `#1C2330` / `#475366` | `#F1F3F7` / `#C6CDD9` | 名称与当前值 |
| 主要操作 | 石墨 `#202532` | 珍珠灰 `#E6E7EB` | 高优先级按钮 |
| 进行 / 完成 / 暂停 / 错误 | `#365879` / `#46586F` / `#656477` / `#90465D` | `#A2CEFF` / `#CBBFFF` / `#D0C5D5` / `#FFB5BC` | 与状态图标、数值或错误原因配合 |

- 环境背景先铺开亮面与背光面，在弧面转折处让高光变亮、变细，再隐入底色。大面积亮面容易泛白时，可用浅蓝灰打底，在局部晕开很淡的薰衣草紫。以表面的相对坐标定位光带，缩放窗口时沿用构图。
- 卡片用自身坐标绘制流光。宽色带在卡面内弯曲、交叠，边缘留少量珠光。给同一对象保留固定的相位偏移，展开、收起或换位时光纹跟随对象。压低文字背后的明暗变化，进度和错误使用各自的语义色。
- 系统要求减少透明度或提高对比度时，使用能清楚承载文字的实色表面。开启减少动态效果时保留静态光泽。

## 布局、操作与反馈

- 配置项适合用列表比较。整行只有一个动作时，让整行响应点击。可独立操作的对象适合用卡片，同组卡片保持一致的内边距、操作顺序和命中区域。
- 选择或编辑某个值的入口紧邻该值。表单里为主要操作留足空间，让字段占用余宽。用真实的多行内容确定输入框高度。文件名、路径等两端都有辨识价值时，从中间省略，并提供读取完整值的方式。
- 同一对象在摘要和详情中沿用相同的状态名称和图标。返回入口在同类详情中保持同一位置。把标题、来源等稳定信息放在临时进度之前，完成后移除进度条时，这些信息仍在原处。
- 空状态说明当前范围内为何没有内容。搜索框已有清除入口、导航已有对应入口时，省去空状态里的重复按钮。首次使用且没有明显的下一步时，可在空状态提供创建入口。
- 让反馈出现在用户能处理它的地方。提交中可在原按钮显示忙碌状态，字段错误紧邻字段，并保留已填内容。影响整个视图且需要用户处理的问题可用页面级提示。图标按钮提供可访问名称，键盘操作保留可见焦点。

## 动画曲线

先判断这次操作改变了什么。选择改变时，可以移动选中标记，让选项留在原位。同一区域替换内容时，可以让旧内容淡出、新内容在相同的对齐线上进入，共用的导航和主要操作保持稳定。直接跳到另一类别时，只呈现起点和目标内容。有空间关系需要说明时，再用位移表达对象的去向或层级的变化。

以下参数以质量 1 为调校起点。刚度影响响应速度，阻尼影响回弹幅度。使用系统动效或其他动画模型时，按“交互表现”一列选择对应曲线。

| 组件或属性 | 曲线 | 交互表现 |
| --- | --- | --- |
| 按钮按下与释放 | 刚度 900，阻尼 60 | 快速压下、平稳复位，命中区域固定 |
| 开关滑块 | 刚度 625，阻尼 40 | 轻微回弹，途中反向沿用当前速度 |
| 导航选中底板、分段选择 | 刚度 484，阻尼 44 | 底板经过中间位置，准确停在选项下方 |
| 面板收合 | 刚度 324，阻尼 36 | 起停从容，边界平稳收敛 |
| 卡片展开与收起 | 刚度 235，阻尼 31 | 从当前轮廓反向，保留速度，平稳停靠 |
| 颜色与文字替换 | 180 ms ease-in-out | 在原位交接，颜色采用感知均匀插值 |
| 有界数值与进度 | 200 ms ease-out | 从当前读数逼近新值，限制在合法范围内 |
| 材质流光 | 连续周期相位 | 用正弦或余弦驱动反光的位置和强度。循环首尾的位置与速度相接，停止时冻结当前相位 |

## 组件连续变形

先确定展开后的占位。原位展开的卡片在父布局内预留详情所需的行列，让相邻对象随布局让位。按阅读方向和可用空间选择扩展方向，遇到末列或底边时向空间充足的一侧展开。由按钮打开的面板以按钮的可见边界为起点，关闭时缩回触发处。

为收合和展开形态保留同一对象标识。取当前可见的矩形作为起点，测量目标布局，让位置、宽高和圆角一起变化。材质随轮廓重绘并延续反光相位。标题、图标保持自然比例，只在详情中出现的内容等空间足够时淡入，收合时提前淡出。

过渡期间允许反向操作。从当前帧的位置、尺寸和速度转向最新目标，取消过期的完成回调。隐藏的控件退出命中区域和焦点顺序，键盘关闭详情后焦点回到触发处。减少动态效果时直接落到目标布局，保留状态和焦点反馈。

## 验收

按本次改动涉及的组件和目标平台支持的输入方式选择场景。

- 用默认界面完成一个常用任务，再展开一个低频选项、修改并返回。检查入口是否好找，已填内容是否保留。切换不相邻的视图时，查看中间帧是否闪过无关内容，下一步要点的控件是否移位。
- 在窄、宽两种布局中放入长名称，分别检查浅色和深色外观。重点看流光最亮处的文字、被省略的内容和主操作能否辨认。
- 对照同一对象的摘要、详情、进行中和完成态，再走一次无结果搜索。检查状态叫法、返回位置、进度消失后的对齐，以及清除操作是否容易找到。
- 从边缘位置展开，在半途收起，再立即展开。观察首帧、中间帧和终点的轮廓、光纹和命中位置。用键盘和减少动态效果模式重复操作，确认最终焦点落在当前可见的控件上。
